# EcoPulse - Серверная часть
## Описание проекта
Backend-приложение для расчетов выбросов загрязняющих веществ от различных источников

## Запуск проекта
### Через Rider
1. Откройте решение (.sln файл) в Rider
2. Выберите проект запуска 
3. Запустите проект

### Через командную строку
Восстановление зависимостей
```
dotnet restore
```
Сборка проекта
```
dotnet build
```
Запуск в режиме разработки
```
dotnet run --project ./EcoPulseBackend/EcoPulseBackend.csproj
```
или из папки проекта:

```
cd ./EcoPulseBackend
dotnet run
```

## Swagger/OpenAPI
После запуска приложения документация API доступна по адресу:

* http://localhost:5000/swagger/index.html

## Сервисы
### EmissionService

Фасад над всеми сервисами расчета выбросов. Упрощает использование в контроллерах и сценариях верхнего уровня. Не содержит собственной бизнес‑логики, а агрегирует специализированные сервисы.

### GasolineGeneratorService | Сервис бензогенератора

- Расчет выбросов по группе загрязнителей (углерода оксид, бензин, азота диоксид, азота оксид, серы диоксид).

### ReservoirsService | Сервис резервуаров

- Расчет выбросов по группе загрязнителей (углеводороды предельные C12 - C19, сероводород).

### DuringMetalMachiningService | Сервис механической обработки металлов

- Расчет выбросов по группе загрязнителей (диЖелезо триоксид).

### DuringWeldingOperationsService | Сервис сварочных работ

- Расчет выбросов по группе загрязнителей (диЖелезо триоксид, марганец и его соединения, фториды газообразные).

### MaximumSingleService | Сервис одиночного точечного источника

- Расчет выбросов по одному загрязнителю (азота диоксид, азота оксид, серы диоксид, углерод диоксид, твердые частицы).
- Расчет зоны выброса.

### VehicleFlowService | Сервис движущегося транспорта

- Расчет выбросов по группе загрязнителей (углерода оксид, азота диоксид, бензин, сажа, серы диоксид, соединения свинца, формальдегид, бенз(а)пирен).
- Расчет нескольких зон выбросов.

### TrafficLightQueueService | Сервис стоящего транспорта на регулируемом перекрестке

- Расчет выбросов по группе загрязнителей (углерода оксид, азота диоксид, бензин, сажа, серы диоксид, соединения свинца, формальдегид, бенз(а)пирен).
- Расчет нескольких зон выбросов.

### OpenCoalWarehouseService | Сервис открытого склада угля

- Расчет выбросов по одному загрязнителю (угольная пыль).
