# EcoPulse - Серверная часть
## Описание проекта
Backend-приложение для расчетов выбросов загрязняющих веществ от различных источников

## Запуск проекта
### Через Rider
1. Откройте решение (.sln файл) в Rider
2. Выберите проект запуска 
3. Запустите проект

### Через командную строку
Восстановление зависимостей
```
dotnet restore
```
Сборка проекта
```
dotnet build
```
Запуск в режиме разработки
```
dotnet run --project ./EcoPulseBackend/EcoPulseBackend.csproj
```
или из папки проекта:

```
cd ./EcoPulseBackend
dotnet run
```

## Swagger/OpenAPI
После запуска приложения документация API доступна по адресу:

* http://localhost:5000/swagger/index.html

## Сервисы
### EmissionService

Фасад над всеми сервисами расчета выбросов. Упрощает использование в контроллерах и сценариях верхнего уровня. Не содержит собственной бизнес‑логики, а агрегирует специализированные сервисы.

### GasolineGeneratorService

Сервис бензогенератора.
- Методы:
    - расчет выбросов по группе загрязнителей.

### ReservoirsService

Сервис резервуаров.
- Методы:
    - расчет выбросов по группе загрязнителей.

### DuringMetalMachiningService

Сервис механической обработки металлов.
- Методы:
    - расчет выбросов по группе загрязнителей.

### DuringWeldingOperationsService

Сервис сварочных работ.
- Методы:
    - расчет выбросов по группе загрязнителей.

### MaximumSingleService

Сервис одиночного точечного источника.
- Методы:
  - расчет выбросов по одному загрязнителю;
  - расчет зоны выброса.

### VehicleFlowService

Сервис движущегося транспорта.
- Методы:
  - расчет выбросов по группе загрязнителей;
  - расчет нескольких зон выбросов.

### TrafficLightQueueService

Сервис стоящего транспорта на регулируемом перекрестке.
- Методы:
  - расчет выбросов по группе загрязнителей;
  - расчет нескольких зон выбросов.

### OpenCoalWarehouseService

Сервис открытого склада угля.
- Методы:
  - расчет выбросов по одному загрязнителю.
